IoT Sensor Jarak merupakan project berbasis Internet of Things yang menggunakan sensor jarak untuk mendeteksi jarak suatu objek secara otomatis. Data hasil pembacaan sensor dapat digunakan untuk mengetahui keberadaan atau jarak objek secara real-time. Project ini merupakan penerapan teknologi IoT dengan menggabungkan perangkat sensor dan mikrokontroler untuk melakukan proses pendeteksian.
